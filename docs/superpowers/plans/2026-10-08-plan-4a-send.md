# Circuit Map Plan 4a: Send or Back Up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** From any tab he can send the whole house (data and pictures) to another device or save a backup as one `.circuitmap` file, a chip in the header always says how many changes have not been sent, deleting a floor offers Save a copy first, and the app nudges him on opening when work has gone a week unsent.

**Architecture:** What the chip, its sheet and the nudge say is worked out in `src/sending.js` (pure, tested) from `model.changesSince` and the time of the last finished send, which is kept on the device with `store.setSetting("sent", ...)`, not in the project file. `src/view/send.js` makes the file (the project plus each floor's picture as a data URL, through `file.serialize` from Plan 1) and hands it to `view/savefile.js` from Plan 3d, which now reports whether the file was really handed over, so the chip only resets on a finished send. The chip lives in `index.html`'s header and is filled by `render()`; the nudge is one more case of the single top banner.

**Tech Stack:** As before: plain ES modules, `node --test`, no dependencies.

**Spec:** `docs/superpowers/specs/2026-10-06-circuit-map-app-design.md` (Saving and moving between devices: Export, The header chip, A nudge to back up; Errors: Deleting a floor; Using it: One banner at the top at a time).

**Plan 4 is split** as Plans 2 and 3 were: 4a Send or back up (this plan); 4b Bring in a file (Import with merge, a different house, Undo import, Send it back, "Moving your project", drop a file on the window); 4c Plates to rewrite (the bar, the list, Swap labels, the chip's "2 plates"); 4d PDF pictures and the Home Screen card.

**Decisions made here**

- On a phone the file is made first and then a "Share it" button hands it over. Safari only opens the Share sheet straight from a tap, and reading several pictures can take longer than it allows, so a single tap would often fall back to a download. On a computer one tap downloads.
- The count is `model.changesSince`: records and deletions. Renaming the house is not counted (it is not a record).
- A house opened from a file starts at "Nothing new to send": what came in is not this device's work.
- The nudge is decided once, when the app opens. With no send yet, the seven days run from the oldest change, so a house started today is not nagged.
- The sheet has only Send or back up for now. Bring in a file and Moving your project join it in 4b.

**Left for later plans on purpose:** Import and everything that follows it (4b); "12 not sent, 2 plates" on the chip and the plates bar in the banner order (4c); "Works without a signal" and the version line in the sheet (with the service worker, Plan 5).

```js
// Sending the house to another device, or backing it up: what the header chip, its sheet and the backup nudge say.
// "Sent" means this device finished handing over a project file. No DOM here.
import { COLLECTIONS, changesSince } from "./model.js";
import { plural, dayText, agoText } from "./flow.js";

const DAY = 86400000;

// The chip in the header. On a phone there is only room for the narrow one.
export function chipText(count) {
  return count ? { wide: `${plural(count, "change")} not sent`, narrow: `Send ${count}` } : { wide: "Nothing new to send", narrow: "Send" };
}

// The first line of the "Move or back up" sheet. sentAt is when this device last finished a send, 0 if never.
export function sendStatus(project, sentAt, now = Date.now()) {
  const count = changesSince(project, sentAt);
  if (!count && !sentAt) return "Nothing to send yet.";
  const last = sentAt ? `Last sent ${dayText(sentAt)}, ${agoText(sentAt, now)}.` : "This house has not been sent or backed up from this device yet.";
  return `${count ? `${plural(count, "change")} not sent` : "Nothing new to send"}. ${last}`;
}

// Whether to say "Back up your work" when the app opens: more than 50 changes are waiting, or work has waited more
// than 7 days (since the last send or, with none yet, since the oldest change). laterAt is when he last tapped
// Later, which hides it for a day.
export function needsBackup(project, sentAt, laterAt, now = Date.now()) {
  const count = changesSince(project, sentAt);
  if (!count || now - laterAt < DAY) return false;
  let since = sentAt;
  if (!since) {
    since = now;
    for (const coll of COLLECTIONS) for (const r of project[coll]) since = Math.min(since, r.updated);
    for (const t of project.deleted) since = Math.min(since, t.at);
  }
  return count > 50 || now - since > 7 * DAY;
}

// "3.2 MB" for a file of that many bytes.
export function sizeText(bytes) {
  return bytes < 1e6 ? `${Math.max(1, Math.round(bytes / 1000))} KB` : `${(bytes / 1e6).toFixed(1)} MB`;
}
```

```js
// Hand a file to him: the Share sheet on a phone (Save to Files, AirDrop, Mail), a download on a computer.
import { h, toast } from "../ui.js";

// Whether saveFile would open the Share sheet for a file of this name and type, rather than download it.
export function willShare(name, type) {
  return matchMedia("(pointer: coarse)").matches && !!navigator.canShare && navigator.canShare({ files: [new File([""], name, { type })] });
}

// True once the file has been handed over; false if he closed the Share sheet without choosing anything. If sharing
// is refused the file is downloaded instead. note is added to the message after a download, which then stays up.
export async function saveFile(name, text, type, note = "") {
  const file = new File([text], name, { type });
  if (willShare(name, type)) {
    try {
      await navigator.share({ files: [file] });
      return true;
    } catch (err) {
      if (err.name === "AbortError") return false;
    }
  }
  const url = URL.createObjectURL(file);
  h("a", { href: url, download: name }).click();
  setTimeout(() => URL.revokeObjectURL(url), 60000);
  toast(`Saved to your Downloads folder as ${name}.${note && " " + note}`, note && { text: "OK", run: () => {} });
  return true;
}
```

```js
// Send or back up: the whole house, pictures included, as one project file. Also the sheet behind the header chip.
import { fileName, serialize } from "../file.js";
import { sendStatus, sizeText } from "../sending.js";
import { h, button, openSheet } from "../ui.js";
import { saveFile, willShare } from "./savefile.js";

const TYPE = "application/json"; // plain JSON, so the Share sheet accepts it

const dataUrl = (blob) => new Promise((resolve, reject) => {
  const reader = new FileReader();
  reader.onload = () => resolve(reader.result);
  reader.onerror = () => reject(reader.error);
  reader.readAsDataURL(blob);
});

// The project file's text: the project, and each floor's picture as a data URL.
async function projectText(app) {
  const images = {};
  for (const floor of app.project.floors) {
    const blob = floor.imageId && await app.store.getImage(floor.imageId);
    if (blob) images[floor.imageId] = await dataUrl(blob);
  }
  return serialize(app.project, images);
}

// Make the file and hand it over. A computer downloads it as soon as it is made. A phone shows "Share it" first: the
// Share sheet only opens straight from a tap, and making the file can take longer than that allows. The house
// counts as sent once the file has really been handed over; after() then runs, if given.
export function exportSheet(app, after) {
  const at = Date.now(), name = fileName(app.project);
  const status = h("p", { role: "status" }, "Preparing file...");
  const actions = h("div", { class: "buttons" });
  const close = openSheet("Send or back up", (close) => [status, actions, button("Cancel", close)]);
  const hand = async (text) => {
    const sent = await saveFile(name, text, TYPE, "To put it on your iPhone: right-click the file, Share, AirDrop.");
    if (!sent) return; // he closed the Share sheet: Share it is still there to try again
    close();
    app.markSent(at);
    if (after) after();
  };
  projectText(app).then((text) => {
    if (!status.isConnected) return; // cancelled while the file was being made
    if (!willShare(name, TYPE)) return hand(text);
    status.textContent = `${name} is ready (${sizeText(new Blob([text]).size)}). AirDrop it to your Mac, or choose Save to Files.`;
    actions.append(button("Share it", () => hand(text), "main"));
  }).catch(() => {
    status.textContent = "The file could not be made. Try again.";
  });
}

// "Move or back up": what the chip in the header opens.
export function sendSheet(app) {
  openSheet("Move or back up", (close) => [
    h("p", {}, sendStatus(app.project, app.sentAt)),
    h("p", { class: "small" }, "Send a copy to your Mac, or save it to iCloud Drive. A copy that never leaves this device does not protect against a lost or wiped phone."),
    h("div", { class: "buttons" },
      button("Send or back up", () => {
        close();
        exportSheet(app);
      }, "main"),
      button("Close", close)),
  ]);
}
```
